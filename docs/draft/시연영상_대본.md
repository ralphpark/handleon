# 핸들온 시연 영상 대본

- 형식: 가로 16:9, 1920×1080, 약 **4분 40초**(3~5분 안).
- 화면: **차량 에뮬레이터**(Pleos Connect Emulator 2.1.0, 1920×720), **아이폰 시뮬레이터**(운전자 휴대폰), **안드로이드 휴대폰**(가족 휴대폰, 화면 미러링으로 녹화).
- 차량 화면은 1920×720 이라 16:9 캔버스 위쪽에 두고, 아래 띠에 자막을 넣습니다. 휴대폰과 함께 보여 줄 때는 차량 화면을 위, 휴대폰 화면을 오른쪽 아래에 작게 둡니다.
- 앱 안의 버튼·문구는 코드(main `533e633`)에 있는 그대로 적었습니다.
- 인물 이름은 가족 관계로만 씁니다: 운전자 **"아버지"**, 가족 **"큰딸"**. 실명·이메일·계정이 화면에 나오지 않게 아래 [녹화 주의](#녹화-주의--실명이메일계정이-나오지-않게)를 꼭 지킵니다.

푸시와 가족 피드는 **가족이 초대를 받은 뒤 새로 올라간 관찰·대화 권유 요약**에만 생기므로, 녹화는 아래 순서로 합니다.

| 순서 | 찍을 것 | 쓰는 장면 | 메모 |
|---|---|---|---|
| R1 | 차 첫 실행과 동의 → 설정 → **발표 모드 켜기** | 3 | 앱을 새로 설치했거나 설정 → 내 데이터 지우기를 한 상태에서 시작. 발표 모드는 **R2 전에** 켭니다(아래 메모) |
| R2 | 차 ↔ 운전자 휴대폰 연결 | 9 | 운전자 계정은 미리 로그인해 둠. 연결 패널에 "발표 모드에서는 재생이 끝날 때 재생 결과만 보내요"가 보이면 맞게 켜진 것 |
| R3 | 가족 초대(바로 공유, 자세한 지표와 편지까지, 운전 패턴 함께) | 10 | "바로 공유"여야 1분 안에 푸시가 옴 |
| R4 | 가족 초대 받기 | 11 | 가족 계정은 미리 로그인해 둠 |
| R5 | 차 24개월을 60초로 보기 → 끝까지 → 가까운 곳 보기 → 길안내 | 4, 5 | 발표 모드에서는 재생이 끝날 때 재생 결과(대화 권유 달 요약과 6개월치 운전 패턴)만 서버로 보냄 |
| R6 | 가족 휴대폰 푸시 → 가족 피드·운전 패턴 | 12, 13 | 재생이 끝나고 1분쯤 안에 도착. 가족 앱은 닫거나 뒤로 보내 둠(앱이 앞에 있으면 알림창 대신 앱 안에 "새 운전 요약이 도착했어요"가 뜸) |
| R7 | 가족이 한마디 보내기 | 14 앞부분 | |
| R8 | 차 홈에서 `tools/drive.sh 60` → 세운 뒤 한마디 카드 → 확인했어요 → 오늘의 한 줄 | 14 뒷부분 | 2분이 안 되는 주행이라 쉬어 가기 카드가 끼어들지 않음. 오늘의 한 줄은 P 로 세우고 30초 뒤 트립이 저장된 다음에 나옴 |
| R9 | 설정 → 엔진 화면 열기 → `tools/drive.sh 150` → 1분쯤 뒤 뒤로 → 주행 화면과 쉬어 가기 문구 → 세운 뒤 홈 → 쉬어 가기 카드 → 15분 타이머 | 6, 7, 8 | R8 뒤 15분이 지나야 연속 운전 시간이 새로 시작됨(그 전이면 R8 부터 이어서 셈). 쉬어 가기 카드는 세운 뒤 30분 동안 홈 맨 위를 차지하므로 R8 을 먼저 찍음 |
| R10 | 차 홈 "잠시 멈추기" → 가족 피드 새로 고침 → 멈춤 카드 | 15 | 쉬어 가기 카드가 떠 있어도 위쪽 공유 상태 줄은 보임 |
| R11 | 운전자 휴대폰 → 가족 공유 관리 → 가족이 보는 화면(멈춤) → 다시 공유 → 가족이 보는 화면(내용) | 16 | |
| R12 | 오프닝·마무리 화면, 앱 목록 | 1, 2, 17 | |

### 준비

- **차량 에뮬레이터**: Pleos Connect Emulator 2.1.0(x86_64)을 켜고 `adb install apk/HandleOn_핸들온_release.apk`. `tools/drive.sh` 는 adb·curl·python3 가 필요하고, Virtual Console(`http://127.0.0.1:8088`)을 씁니다. 휴대폰이 함께 연결돼 있어도 Pleos 에뮬레이터에만 보냅니다.
- **녹화 시각은 한국 시각 낮**: 엔진 화면은 위치와 시각으로 해가 졌는지 계산해, 밤이면 "밤이거나 와이퍼가 켜져 판단을 쉬어요"로 나옵니다.
- **휴대폰 역할**: 서버 푸시(FCM)는 안드로이드에서만 받으므로 **가족 = 안드로이드 휴대폰**(`adb install apk/HandleOn_핸들온_휴대폰_release.apk`), **운전자 = 아이폰 시뮬레이터**(빌드는 `phone/README.md` 의 `--dart-define` 설정). 아이폰 시뮬레이터에는 카메라가 없어 9번 장면에서는 6자리 코드를 넣습니다.
  - QR 을 카메라로 찍는 모습이 꼭 필요하면: 안드로이드 휴대폰에서 **운전자** 계정으로 로그인해 QR 을 찍어 연결 → 로그아웃 → **가족** 계정으로 다시 로그인. 같은 운전자 계정은 아이폰 시뮬레이터에서 로그인해 10·16번을 찍습니다(연결은 운전자 계정에 묶여 있음).
- **발표 모드를 연결 전에 켜는 이유**: 발표 모드가 꺼진 채 연결하면 차가 실제 기록으로 이번 달 '적립 중' 요약을 올립니다. 재생 결과는 재생 인물의 마지막 달(2026년 10월)로 올라가므로, 11월에 녹화하면 가족 피드 맨 위에 11월 '적립 중' 카드가 먼저 보여 대화 권유 카드가 가려집니다. 발표 모드에서는 실제 주행 기록을 서버로 올리지 않고 재생 결과만 보냅니다.
- **다시 찍을 때**: 같은 달 요약이 같은 내용으로 다시 올라가면 단계가 바뀌지 않아 푸시가 새로 생기지 않습니다. R5~R6 을 다시 찍으려면 새 운전자 계정과 새 초대로 R2 부터 합니다.
- **24개월 재생**: 한 달에 2.5초씩 약 60초. 재생 화면을 벗어나면 멈추므로 "마지막 기록까지 보셨어요"가 나온 뒤 가까운 곳 보기를 누릅니다(끝나야 서버로 보냄).
- **오늘의 한 줄**: 문구는 날짜에 따라 바뀝니다(마음 운전 7가지). 촬영 날 나오는 문구를 자막에 맞춰 적습니다. 치매안심센터 안내 문구가 나오는 날은 "가까운 곳 보기" 버튼도 함께 나옵니다.
- **집 즐겨찾기**: 내비에 실제 집 주소를 등록하지 않습니다. 등록하지 않으면 홈에 "집을 즐겨찾기에 등록하면 생활 반경을 볼 수 있어요"가 보일 수 있는데 그대로 둡니다. `drive.sh` 의 출발점도 판교 근처 가짜 좌표입니다.

## 녹화 주의 — 실명·이메일·계정이 나오지 않게

- **가입·로그인 화면은 찍지 않습니다.** 이메일·비밀번호 칸이 나오므로 두 휴대폰 모두 녹화 전에 로그인을 끝냅니다. 가입 때 이메일 확인 링크를 누르는 과정도 녹화하지 않습니다.
- **"가족에게 보일 이름"은 관계 이름만**: 운전자 "아버지", 가족 "큰딸". 이 이름이 차 화면("큰딸 님의 한마디"), 공유 목록, 초대 문장, 가족 피드에 그대로 나옵니다.
- **계정 메뉴(오른쪽 위 설정 아이콘)를 열지 않습니다.**
- **안드로이드 휴대폰**: 방해 금지를 켜고 핸들온 알림만 허용, 알림창에 다른 앱 알림이 없게 정리, 상태 표시줄의 계정·통신사·메신저 아이콘을 확인합니다. 화면 미러링 창 제목에 기기 이름·시리얼이 나오면 잘라 냅니다.
- **아이폰 시뮬레이터**: 창 제목의 기기 이름만 보이게 하고, 다른 앱·사진·연락처를 열지 않습니다.
- **터미널**: 프롬프트에 사용자 이름·컴퓨터 이름·홈 폴더 경로가 나오지 않게 녹화 전에 `PS1='$ '` 로 바꾸고 저장소 폴더에서 `tools/drive.sh 150` 만 보이게 합니다. `adb devices` 처럼 기기 시리얼이 나오는 명령은 찍지 않습니다.
- **브라우저(Virtual Console)**: 프로필 아이콘·북마크 바·다른 탭을 숨기거나 화면에 넣지 않습니다.
- **개발 도구 화면은 넣지 않습니다**: Android Studio, Supabase 대시보드, Firebase 콘솔(프로젝트 이름·키·이메일이 보임).
- **초대 코드·연결 코드**: 시연용 계정의 코드라 10분(연결)·7일(초대) 뒤 만료되지만, 녹화가 끝나면 공유를 끊고 시연용 계정을 정리합니다.
- **내레이션·자막**에 실명·소속·연락처를 말하거나 적지 않습니다. 영상 파일 이름과 올리는 채널 이름에도 계정·실명이 드러나지 않게 합니다.
- **화면 녹화 도구**의 워터마크·사용자 이름 표시를 끕니다.

## 표현 주의

- 재생 장면(4·5·12·13)에는 "가상 인물 데이터"가 화면과 자막에 늘 보이게 둡니다.
- "치매를 예방·진단한다", "위험 점수" 같은 말을 쓰지 않습니다. "운전 습관의 변화를 평소의 나와 견주어 알려 드린다", "이야기 나눌 때를 알려 드린다", "3·3·3 수칙을 챙기도록 돕는다"로 말합니다.
- 엔진 성능 숫자를 영상에 넣는다면 "합성 데이터로 한 엔진 동작 검증, 임상 검증 아님"을 같은 화면에 적습니다.
