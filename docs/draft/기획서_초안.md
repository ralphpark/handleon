# 02 앱 프로젝트 소개 / 심사 자료

## 1. 앱 한 줄 소개

**운전 습관의 작은 변화를 '평소의 나'와 견주어 알려 주고, 가족과 이야기 나눌 때를 운전자가 고른 범위와 시점으로 함께 나누는 Pleos Connect 차량 앱.**

양식 글자 수가 짧을 때 쓸 문구:

- (30자 안쪽) 평소의 내 운전과 오늘을 조용히 견주는 차량 앱
- (50자 안쪽) 차가 아는 운전 습관으로 '평소의 나'와 견주고, 나눌지는 운전자가 정하는 차량 앱

---

## 2. 기획 배경

**가족은 부모님의 운전이 걱정되지만 물어볼 근거도 계기도 없습니다. 지금 있는 방법(실시간 위치 공유, 모두에게 같은 기준을 대는 경고, 면허 반납 권유)은 운전자를 지켜보는 대상으로 만들어 오래 쓰이지 못합니다. 핸들온은 차가 이미 아는 신호로 운전자 본인의 기준선을 만들고, 달라진 상태가 이어질 때 "이야기 나눠 볼 때"를 알려 주며, 무엇을 누구와 언제 나눌지는 운전자가 정하게 합니다.**

### 2-1. 우리가 주목한 순간

| 누구 | 불편한 순간 | 속마음 |
|---|---|---|
| 멀리 사는 자녀 | 명절에 오랜만에 부모님 차를 탔는데, 늘 다니던 길에서 내비를 켜시는 모습이 마음에 걸린다. 그런데 전화로 "요즘 운전 괜찮으세요?"라고 묻기도, 위치 추적 앱을 깔아 드리자고 하기도 어렵다. | 걱정은 되는데 근거 없이 말을 꺼내면 서운해하실 것 같다. |
| 60세 이상 운전자 | 장보기·병원·복지관을 다니는 차는 생활의 독립이다. 스스로 달라진 점을 알아차리기 어렵고, 가족의 걱정이 곧바로 "면허 반납" 이야기로 번질까 봐 운전 이야기를 피하게 된다. | 지켜보이는 것은 싫지만, 달라진 게 있다면 먼저 알고 싶다. |
| 20~50대 운전자 | 야근 다음 날의 출근길, 주말 귀성길처럼 피곤한 날에도 쉬어 갈 때를 놓친다. | 오늘 내 운전이 평소와 다른지 가볍게 알려 주면 좋겠다. |

### 2-2. 왜 해결이 필요한가

- **고령 운전자가 빠르게 늘고 있습니다.** 65세 이상 운전면허 소지자는 2019년 333만 명에서 2023년 474만 명으로 42.3% 늘었고, 75세 이상도 처음으로 100만 명을 넘었습니다(경찰청 자료). 2024년에는 약 517만 명으로 집계됩니다(국회예산정책처 분석 인용). 경찰청은 2040년 65세 이상 운전자를 1,300만 명 수준으로 전망합니다.
- **사회의 이야기는 '나이'에 머물러 있습니다.** 2024년 교통사고 196,349건 중 65세 이상 운전자가 가해자인 사고가 42,369건(21.6%)으로, 해마다 비중이 커지며 면허 반납 논의가 이어집니다(도로교통공단 통계 인용 자료). 그러나 같은 나이라도 운전 습관은 사람마다 다르고, 한 사람의 변화는 그 사람의 평소와 견줄 때 보입니다.
- **가족이 함께 살필 계기가 필요합니다.** 2023 치매역학조사(보건복지부, 2025년 3월 발표)에서 65세 이상 치매 유병률은 9.25%, 경도인지장애 유병률은 28.42%였습니다. 핸들온은 이런 판단을 하지 않습니다. 운전 습관의 변화를 본인 기준과 견주어 알려 주고, 가족과 이야기할 때를 알려 주며, 원하면 가까운 치매안심센터(만 60세 이상 무료 선별검사)로 가는 길을 순정 내비로 이어 주는 데까지만 돕습니다.

### 2-3. 지금 있는 방법의 한계

| 방식 | 가족에게 보이는 것 | 비교 기준 | 동의와 통제 | 한계 |
|---|---|---|---|---|
| 휴대폰 위치 공유 앱 | 실시간 위치, 이동 경로 | 없음(보는 사람이 해석) | 켜기·끄기 | 지켜보이는 느낌 때문에 거부감이 크다. 운전인지 탑승인지 구분하지 못한다. |
| 보험 연계 안전운전 점수 | 운전자 본인의 점수 | 모든 사람에게 같은 기준 | 보험 계약과 묶임 | 운전 기록이 보험 계약에 쓰인다. 가족과 나누는 설계가 아니다. |
| 일본 오릭스 에버드라이브(2017~약 2022) | 가족에게 실시간 위치와 366일치 주행 경로, 급가속 같은 이벤트 | 고정 기준 이벤트 | 계약할 때 한 번 동의 | 지켜보는 쪽 중심의 구조. 운전자가 범위·시점을 고를 수 없다. |
| **핸들온** | 운전자가 고른 범위의 요약(단계만 / 추이 그래프까지 / 자세한 지표와 편지까지)과 월별 집계 패턴 | **운전자 본인의 기준선** | 받는 사람마다 범위·시점·운전 패턴 공유를 고르고(기본값 없음), 차·휴대폰에서 한 번에 멈추거나 모두 끊고, "가족이 보는 화면"으로 확인 | 원본 위치는 차 밖으로 나가지 않는다. 경로 대신 집계를 나눈다. |

### 2-4. 왜 휴대폰이 아니라 차인가

휴대폰은 지금 운전 중인지 탑승 중인지, 어느 차인지 모릅니다. 핸들 흔들림, 브레이크, 방향지시등, 차로 유지 보조, 와이퍼, 순정 내비의 길안내·재탐색 같은 신호도 휴대폰으로는 얻을 수 없습니다. 그리고 운전 중에 울리는 휴대폰 알림과 달리, 차는 지금 달리는 중인지 멈췄는지를 압니다. 핸들온은 이 세 가지(정확한 운전 신호, 순정 내비와의 결합, 주행·정차 맥락)를 Pleos Connect 에서만 가능한 가치로 삼습니다. 자세한 내용은 3-2에 있습니다.

## 3. 앱 주요 기능 및 차량 특화 요소

**차가 1초마다 보내는 신호를 차 안의 엔진(드라이브프린트)이 트립 지표로 바꿔 '평소의 나'와 견줍니다. 달리는 동안에는 말을 걸지 않고, 주차한 뒤에만 카드 한 장으로 알려 줍니다. 가족과 나눌지, 무엇을 언제 나눌지는 운전자가 정합니다.**

### 3-1. 핵심 기능

| 기능 | 해결하는 문제 | 차량에서 주는 새로운 경험 |
|---|---|---|
| **드라이브프린트 엔진** | "남들보다 어떤가"가 아니라 "평소의 나보다 어떤가"를 알려 준다. | 15개 지표(생활 반경 7, 길찾기 3, 조작 5)를 트립마다 차 안에서 계산한다. 원본 1초 신호는 지표로 바꾼 뒤 버린다. |
| **마음 운전**(60세 이상) | 몇 달에 걸친 작은 변화를 스스로 알아차리기 어렵다. | 월 단위로 안정 → 관찰 → 대화 권유를 보여 주고, 대화 권유 때는 가까운 치매안심센터와 순정 내비 길안내로 바로 이어진다. |
| **운전 컨디션**(20~50대) | 피곤한 날 쉬어 갈 때를 놓친다. | 지난 28일의 나와 오늘을 견주고, 이틀 연속 평소 범위를 넘으면 "오늘은 쉬어 가시면 좋겠어요"라고 알린다. 밤·비 운전은 판단을 쉰다. |
| **주행 화면과 쉬어 가기** | 운전 중 화면 조작은 주의를 흩뜨린다. | 주행 중에는 조작 없는 화면 한 장. 2시간 넘게 이어 운전하면 정적인 문구 한 줄만 더한다. |
| **주차한 뒤에만 보이는 카드** | 운전 중 알림은 주의를 흩뜨리고, 운전자에게 건넬 말은 멈춘 뒤가 좋다. | 쉬어 가기(커피 + 15분 안쪽 낮잠 타이머), 가족 한마디, 오늘의 한 줄(3·3·3)을 주차 뒤 한 장씩 보여 준다. |
| **운전자가 쥐는 가족 공유** | 공유는 한 번 동의하면 끝나는 게 아니라, 받는 사람과 때에 따라 달라야 한다. | 받는 사람마다 범위·시점·운전 패턴 공유를 고르고, 차 화면에서도 한 번에 멈춘다. "가족이 보는 화면"으로 가족 휴대폰에 보이는 그대로를 확인한다. |
| **운전 패턴(집계)** | 가족은 경로가 아니라 "요즘 어떻게 다니시는지"가 궁금하다. | 월별 운전 횟수·시간·운전한 날, 밤·30km 넘는 운전 비율, 다니는 범위·가는 곳 가짓수를 평소 대비 비율로만 나눈다. 장소 이름·좌표·km 값은 보내지 않는다. |

#### 드라이브프린트 엔진(구현)

- **지표 15개와 근거 등급**: A·B 는 공개 연구(미국 DRIVES·LongROAD 고령 운전자 코호트 등)에서 보고된 지표로 영역 지수 가중치 A 1.0, B 0.6 입니다. C 는 Pleos 의 내비·차량 신호로 처음 잴 수 있는 가설 지표라 가중치를 0.3으로 낮췄고, 화면에도 "Pleos 지표, 검증 중"이라고 표시합니다.

  | 영역 | 지표(등급) | 쓰는 신호 |
  |---|---|---|
  | 생활 반경 | 트립 수, 운전한 날, 8~16km 나들이, 야간 비율, 목적지 수, 목적지 다양성, 집에서 거리(모두 A) | 기어·속도(AAOS), GPS, 위치·시각으로 계산한 일몰 |
  | 길찾기 | 좌회전 비중(B) | GPS 방위각 변화(없으면 NaviHelper 회전 안내) |
  | | 익숙한 길 재탐색(C), 익숙한 곳 길안내(C) | NaviHelper 안내 시작·재탐색 + 6개월 동안 5번 넘게 간 '익숙한 목적지' |
  | 조작 | 과속 비율(A) | 속도(AAOS) + 제한속도(NaviHelper) |
  | | 급제동(A) | 속도(AAOS) + 브레이크 페달(Pleos Vehicle) |
  | | 직진 핸들 흔들림(B) | 조향각(Pleos Vehicle), 시속 40km 넘는 곧은 길 |
  | | 방향지시등 누락(C) | 방향지시등(Pleos Vehicle) + 내비가 예고한 회전(NaviHelper TBT) |
  | | 차로 유지 보조 개입(C) | 경고등 LKA(Pleos Vehicle Safety) |
  | 판단 보류 | 비 오는 날, 밤 | 앞 와이퍼(Pleos Vehicle), 일몰 계산 |

- **본인 기준선**: 운전자마다 기준 기간의 중앙값·MAD 로 수정 z 를 내고, 영역별 지수의 개인 임계값(기준 기간 95백분위, 최소 1.5)을 씁니다.
- **라벨**: 운전자가 오늘·어제에 "잠을 설쳤어요 / 감기 / 새 약 / 여행 / 차가 바뀜" 라벨을 붙이면 그날은 판단에서 뺍니다. 차가 바뀌거나 집이 1km 넘게 바뀌면 기준선을 다시 쌓습니다.
- **대화 권유 규칙**: 가장 최근에 끝난 달에 2개 이상 영역이 개인 임계값을 넘고, 그중 하나 이상이 그 앞에 평가된 달에도 넘었을 때 '대화 권유'입니다. 한 영역이라도 넘으면 '관찰', 넘은 영역이 없으면 '안정'입니다. 관찰·대화 권유일 때는 주별 지수에 베이즈 변화점 탐지(BOCPD)를 써서 "약 N주 전부터 달라졌어요"를 함께 보여 줍니다.
- **말투**: 결과는 "차로 외출하시는 횟수가 평소보다 줄었어요"처럼 쉬운 문장 최대 3개로 보여 주고, 문장마다 "연구 근거 있는 지표" 또는 "Pleos 지표, 검증 중"을 붙입니다. 엔진 문구와 월간 편지에는 금지어 8개를 두고, 들어가지 않는지 시험으로 확인합니다.

#### 마음 운전(60세 이상, 구현)

- 첫 실행에서 태어난 해를 넣으면 60세 이상은 '마음 운전'이 미리 골라집니다(직접 고르거나 설정에서 바꿀 수 있음).
- 홈: 3영역 링 게이지(점선 = 평소 범위), 단계 문구("평소와 비슷해요 / 평소와 조금 달라진 점이 있어요 / 가족과 이야기 나눠 보시면 좋겠어요"), 평소와 달라진 점, 이번 달 편지, "지난 기록" 탭(월별 추이).
- **대화 권유일 때**: "가까운 곳 보기" → 가까운 치매안심센터 3곳(공공데이터 306곳, 차 안에서만 거리 계산, "60세 이상은 무료로 선별검사를 받을 수 있어요") → "길안내" 한 번으로 순정 내비가 경로를 잡습니다.
- **월간 운전 편지**: 휴대폰과 연결되어 있으면 서버가 그달 단계와 달라진 점(지표 코드·방향만)으로 짧은 편지를 만듭니다(Anthropic Claude API). 위치·자유 입력은 보내지 않고, 금지어·거절·시간 초과(20초)는 안전한 고정 편지로 바꿉니다.

#### 운전 컨디션(20~50대, 구현)

- 조작 지표(급제동, 직진 핸들 흔들림, 차로 유지 보조 개입)를 하루 단위로 보고, 최근 14운전일 막대그래프로 보여 줍니다.
- 7운전일이 모이면 비교를 시작하고, 지난 28일의 나와 견준 지수가 이틀 연속 점선을 넘으면 "오늘은 쉬어 가시면 좋겠어요"를 띄웁니다. 밤이나 비(와이퍼) 운전은 "오늘은 밤·비 운전이라 판단을 쉬어요"로 둡니다.

#### 주행 화면과 주차 뒤 카드(구현)

- **주행 화면**: AAOS 의 화면 제한 상태(CarUxRestrictions)가 "주의 분산 최소화"를 요구하면 앱 전체가 "핸들온이 함께하고 있어요" 한 장으로 바뀝니다. 버튼이 없습니다.
- **쉬어 가기(주행 중)**: 15분 넘게 쉬지 않고 이어 운전한 시간이 2시간을 넘으면 주행 화면에 "오래 운전했어요. 다음 휴게소에서 잠깐 쉬어 가요"와 연속 운전 시간만 정적으로 더합니다.
- **주차 뒤 카드**: 한 번에 한 장, 우선순위는 쉬어 가기 → 가족 한마디 → 오늘의 한 줄입니다.
  - 쉬어 가기: 오래 운전하고 세운 뒤 30분 안에 "커피 한 잔을 마시고 15분 안쪽으로 짧게 눈을 붙여 보세요"와 15분 타이머. 다 되면 소리 알림 "15분이 지났어요. 몸을 천천히 풀고 출발해요". 다시 달리기 시작하면 타이머를 끕니다.
  - 가족 한마디: 가족이 휴대폰에서 보낸 120자 이내 한마디. 차가 멈춘 뒤에만 보이고, "확인했어요"를 누르면 가족 휴대폰에 "읽음"으로 바뀝니다.
  - 오늘의 한 줄: 그날 운전한 뒤 보건복지부 치매예방수칙 3·3·3을 챙기도록 돕는 문구가 날마다 바뀝니다(걷기, 골고루 먹기, 읽고 쓰기, 안부 전화, 정기 건강검진, 청력·시력 점검, 치매안심센터 무료 선별검사 안내). 카드 아래에는 "핸들온은 질병을 진단하거나 예방하지 않아요"를 함께 적습니다.

#### 가족 공유(휴대폰 앱, 구현)

- **차 연결**: 차 화면 설정 → 휴대폰 연결의 QR(또는 6자리 코드, 10분 유효)을 휴대폰 앱으로 찍습니다. 차는 익명 계정으로 서버에 붙고, 연결된 운전자의 행만 읽고 쓰도록 RLS 로 묶입니다.
- **초대**: 운전자가 받는 사람마다 ① 범위(단계만 / 추이 그래프까지 / 자세한 지표와 편지까지) ② 시점(바로 / 3·7·14일 뒤) ③ 운전 패턴 공유 여부를 **모두 골라야** 8자리 초대 코드(7일 유효)가 만들어집니다. 기본값이 없습니다. 3·7·14일 뒤로 두면 요약이 나온 뒤 운전자가 먼저 살펴볼 수 있습니다.
- **통제**: 받는 사람마다 바꾸기·공유 끊기, 전체 "잠시 멈추기"(휴대폰·차 화면 어디서나), 차 화면의 "모두 끊기". 멈춘 동안 가족 화면에는 "○○ 님이 공유를 잠시 멈췄어요"만 보이고, 대기 중이던 알림은 취소되며 새 알림도 만들지 않습니다.
- **가족이 보는 화면**: 운전자가 휴대폰에서 받는 사람별로 지금 그 가족에게 보이는 화면을 그대로 봅니다. 가족 피드와 미리보기는 서버의 같은 함수로 만들어 결과가 같습니다.
- **가족 피드와 푸시**: 관찰·대화 권유 단계가 된 달의 요약이 운전자가 정한 시점에 열리면 1분 안에 "새 운전 요약이 도착했어요" 푸시가 갑니다(알림 문구에는 단계를 쓰지 않음). 대화 권유일 때 가족 화면에는 "운전 이야기로 가볍게 말을 꺼내 보세요. 요즘 어디를 다니시는지 여쭤보는 것부터 좋아요."를 함께 보여 줍니다.
- **약속**: 차·휴대폰 화면 모두에 "핸들온은 운전 기록을 보험사·면허 기관·광고·데이터 판매에 넘기지 않아요"를 적었습니다.

#### 그 밖의 기능(구현)

- **지난 운전 기록 가져오기**: 운전자가 휴대폰에서 구글 지도 타임라인 내보내기 파일을 고르면, 휴대폰이 차로 이동한 구간(300m 이상)의 출발·도착 시각과 위치(소수 셋째 자리로 반올림), 거리만 뽑아 비공개 폴더에 올립니다. 차가 받는 즉시 서버에서 지우고, 지난 기록으로 기준선을 일찍 쌓습니다.
- **내 데이터 지우기**: 수집을 멈추고 마지막 트립 저장까지 끝난 뒤 이 차의 운전 지문과 라벨을 모두 지우고 첫 실행 화면으로 돌아갑니다.
- **24개월을 60초로 보기**: 가상 인물(아버지)의 24개월 기록을 실제 엔진에 한 달씩 넣어 안정 → 관찰 → 대화 권유로 바뀌는 과정을 보여 줍니다. 화면에 "재생 중 · 가상 인물 데이터"를 늘 띄웁니다.
- **발표 모드 엔진 화면**: Pleos 신호(속도·제한속도·기어·조향각·방향지시등·와이퍼·브레이크·경고등·길안내)가 들어오는 대로 이번 트립의 지표가 2초마다 다시 계산되는 모습을 보여 주는 시연용 읽기 화면입니다.

### 3-2. 차량 특화 요소 — 휴대폰으로는 줄 수 없는 가치

1. **차가 실제로 달린 기록만 잽니다.** 휴대폰은 탑승과 운전을 섞지만, 핸들온은 그 차의 기어(D/R → P 30초)와 속도로 트립을 자릅니다.
2. **휴대폰에 없는 조작 신호를 씁니다.** 조향각, 브레이크 페달, 방향지시등, 차로 유지 보조 경고등, 앞 와이퍼, 순정 내비의 제한속도를 Pleos Vehicle SDK·NaviHelper·AAOS 에서 직접 받습니다.
3. **순정 내비와 묶인 길찾기 지표**: "익숙한 곳에 갈 때 길안내를 켜는 일", "자주 가던 길에서 길을 다시 찾는 일"은 내비 안내·재탐색 이벤트를 받을 수 있는 차량 앱만 잴 수 있습니다.
4. **주행·정차 맥락을 압니다.** 달리는 동안에는 말을 걸지 않고, 멈춘 뒤에만 카드를 보여 줍니다. 가족 한마디도 주차한 뒤에만 차 화면에 나옵니다.
5. **차 안에서 바로 행동으로 이어집니다.** 대화 권유 → 가까운 치매안심센터 → 길안내 한 번, 장거리 → 휴게소 주차 → 15분 타이머.
6. **할 일을 주지 않습니다.** 위치를 '항상 허용'으로 두면 앱을 열지 않아도 시동 직후부터 모읍니다(포그라운드 서비스, 부팅 수신). 고령 운전자에게 "앱 켜기"를 요구하지 않습니다.
7. **원본 위치가 차 밖으로 나가지 않습니다.** 1초 신호는 트립 지표로 바꾼 뒤 버리고, 가까운 센터 계산도 차 안에서 합니다. 서버에는 월·일 집계와 단계(그리고 월간 편지)만 저장합니다.

### 3-4. 창의성 — Pain point, Needs, 해결 방식

| Pain point | Needs | 핸들온의 해결 방식 |
|---|---|---|
| 가족이 걱정을 말로 꺼낼 근거와 계기가 없다 | 감정이 아닌 근거, 정해진 때 | 본인 기준선과 견준 단계와 쉬운 문장, 대화 권유 때 가족 화면의 말 꺼내기 안내 |
| 운전자는 지켜보이는 것이 싫다 | 내가 정하는 공유 | 받는 사람마다 범위·시점·패턴 선택(기본값 없음), 원터치 멈춤·모두 끊기, 가족이 보는 화면 |
| "나이가 많으니"라는 일괄 기준이 억울하다 | 나와 견주는 비교 | 평균이 아니라 '평소의 나', 라벨과 판단 보류로 사정 반영 |
| 위치·경로 공유는 부담이 크다 | 요즘 어떻게 다니시는지만 | 경로 대신 월별 집계, 평소 대비 비율만 |
| 걱정이 생겨도 무엇을 해야 할지 모른다 | 다음 한 걸음 | 가까운 치매안심센터와 순정 내비 길안내, 3·3·3 오늘의 한 줄 |
| 피곤한 날 쉬어 갈 때를 놓친다 | 운전 중 방해 없는 알림 | 주행 중 정적 문구 한 줄, 주차 뒤 커피 + 15분 타이머 |

**차별점 요약**

- **운전자가 공유의 열쇠를 쥡니다.** 동의는 계약 때 한 번이 아니라 받는 사람마다, 언제든 바꿀 수 있습니다. 오릭스 에버드라이브가 계약 때 한 번 동의로 가족에게 실시간 위치와 366일 경로, 고정 기준 이벤트를 보여 준 것과 반대 방향입니다.
- **비교 기준은 평균이 아니라 본인입니다.** 같은 70대라도 평소가 다릅니다.
- **경로 대신 집계를 나눕니다.** 장소 이름·좌표·km 값 열 자체가 서버 표에 없습니다.
- **판단하지 않고 대화의 계기를 줍니다.** "가족과 이야기 나눠 보시면 좋겠어요"가 가장 강한 표현입니다.
- **근거를 숨기지 않습니다.** 지표마다 근거 등급을 보여 주고, 엔진 성능도 "합성 데이터로 한 동작 검증"이라고 밝힙니다.

### 4-2. 멀리 사는 자녀 — 다른 도시에 사는 40대 딸

## 5. 개발 계획

**Pleos Connect Emulator 2.1.0 에서 도는 차량 앱(Kotlin, Jetpack Compose)과 자체 엔진, 휴대폰 앱(Flutter), Supabase 서버까지 끝에서 끝으로 이어지는 시제품을 만들었습니다. 개발 서버·에뮬레이터·실기기에서 차 연결, 월 요약, 월간 편지, 가족 공유·피드, FCM 푸시, 지난 기록 가져오기, 공유 일시중지·모두 끊기, 운전 패턴 공유, 가족이 보는 화면, 가족 한마디를 확인했습니다.**

### 5-1. 구성

```
[차량: Pleos Connect (AAOS)]                                  [서버: Supabase]
 Pleos Vehicle SDK ─┐                                         Postgres + RLS + RPC
 NaviHelper ────────┤ 1초 샘플 → 트립 지표 → 드라이브프린트 엔진    monthly_summaries / daily_conditions
 AAOS 속도·기어 ─────┤   (원본 신호는 버림, Room 에 지표만)        monthly_patterns / family_notes
 GPS ───────────────┘          │                                Edge Functions: monthly-letter(Claude API)
 CarUxRestrictions → 주행 화면   │ 월·일 집계·단계·패턴만 업로드 ──▶ dispatch-notifications(FCM) ← pg_cron 1분
 NaviHelper.requestRoute ← 대화 권유 → 가까운 치매안심센터(차 안 계산)   Storage imports(지난 기록, 받으면 삭제)
                                                                        │
                                              [휴대폰: Flutter, 운전자·가족 공용] ◀──┘
                                               차 연결(QR) · 초대 · 공유 관리 · 가족이 보는 화면
                                               가족 피드 · 운전 패턴 · 한마디 · 푸시(FCM)
```

### 5-5. 엔진 동작 검증 — 임상 검증이 아니라 엔진 동작 검증

가상 운전자 200명(정상군 100, 변화군 100) × 30개월을 합성 코호트 시뮬레이터로 만들어 엔진을 그대로 돌렸습니다(`./gradlew :sim:run`, 시드 7).

| 항목 | 결과 |
|---|---|
| 변화군 중 대화 권유가 나온 비율(민감도) | **0.74** |
| 정상군 대화 권유 | **0회/인년** |
| 중앙 선행 시간 | **4.5개월** |
| 정상군에서 '관찰'이 나온 달 | 0.7% |
| 대화 권유 규칙 비교 | "같은 두 영역이 두 달 연속" 규칙 0.31 → 지금 규칙("이번 달 2개 이상 영역, 그중 하나는 지난달에도") 0.74, 정상군 오경보는 둘 다 0 |

- **가정값**: 변화 시작 10~16번째 달, 6개월에 걸쳐 직선 변화 — 트립 ×0.75, 장소 수 ×0.7, 집에서 거리 ×0.7, 야간 ×0.5, 익숙한 길 재탐색 ×2, 익숙한 곳 길안내 0.05→0.25, 방향지시등 누락 0.10→0.20, 좌회전 비중 0.45→0.38. 교란: 겨울 트립 ×0.85, 명절 장거리, 연 1~2회 감기 주간(트립 ×0.5), 장마철 비.
- 선행 시간의 기준점은 '변화 시작 + 12개월'로 **가정**한 값이며 실제 임상 전환 시점이 아닙니다.
- 변화의 크기는 연구의 방향을 따른 **가정값**이라, 이 숫자는 실제 사람에서의 성능을 뜻하지 않습니다. 엔진이 설계대로 "평소의 나"와 견주고, 정상적인 흔들림(겨울·명절·감기·장마)에 쉽게 흔들리지 않는지를 확인한 결과입니다. 국내 실주행 검증은 공모전 이후 과제입니다.
- 결과 그림: `docs/sim/detection.svg`(탐지 비율), `docs/sim/false_alarms.svg`(정상군 오경보), `docs/sim/lead_time.svg`(선행 시간), `docs/sim/example_persona.svg`(변화군 예시).

### 5-6. 데이터와 안전 설계

- **원본 위치는 차 밖으로 나가지 않습니다.** 1초 신호는 트립 지표로 바꾼 뒤 버립니다. 서버에는 운전 기록으로 월·일 집계와 단계(그리고 월간 편지)만 저장합니다. 유일한 예외인 지난 기록 파일은 차가 받는 즉시 지웁니다.
- **경로 대신 집계**: `monthly_patterns` 표에는 지명·좌표·km 값 열이 없고, 범위 검사로 값을 묶습니다. 다니는 범위·가는 곳 가짓수는 본인 기준 대비 비율로만 올립니다.
- **영역 값도 비율로**: 월 요약의 영역 값은 '영역 지수 ÷ 개인 임계값'으로 올려, 휴대폰은 개인 임계값 자체를 모릅니다.
- **공유는 서버가 강제**: 범위·시점은 RPC 와 RLS 가 지키고, 발송 직전에 현재 동의를 다시 확인합니다. 철회·일시중지 때 대기 알림을 취소합니다.
- **편지는 최소 입력**: 월·모드·단계·지표 코드와 방향만 보냅니다. 위치 필드와 자유 입력은 요청 검사에서 막습니다.
- **주행 중 방해 없음**: 주행 중에는 조작 없는 화면, 서버 조회도 주차하고 화면이 앞에 있을 때만 합니다.
- **표현 원칙**: 의료기기가 아님을 첫 실행 동의, 차 화면(홈·편지·센터·재생) 하단, 휴대폰 앱에 적고, 엔진 문구와 편지의 금지어를 시험으로 막습니다.

## 6. 기대효과 및 발전 가능성

**운전자는 지켜보이지 않으면서 자신의 변화를 먼저 알고, 가족은 근거와 계기를 갖고 먼저 말을 겁니다. 시동과 함께 자동으로 모으고 매달 요약·편지가 돌아오는 구조라 오래 쓰이고, Pleos Connect 탑재 차량이 늘수록 함께 커집니다.**

### 6-1. 사용자 가치

| 누구 | 가치 |
|---|---|
| 60세 이상 운전자 | 내 평소와 견준 변화를 남보다 먼저 압니다. 공유 범위·시점을 직접 정하고 언제든 멈출 수 있어 운전 이야기를 피하지 않아도 됩니다. 필요할 때 가까운 치매안심센터까지 길안내 한 번. |
| 멀리 사는 가족 | 위치를 지켜보지 않고도 "요즘 어떻게 다니시는지"를 압니다. 걱정을 말로 꺼낼 근거와 때, 말 꺼내는 방법까지 받습니다. 한마디는 주차한 뒤에만 전해져 운전을 방해하지 않습니다. |
| 20~50대 운전자 | 오늘의 운전이 평소와 다른지 알고, 장거리에서 쉬어 갈 때를 놓치지 않습니다. |
| 현대자동차그룹·Pleos | 차량 신호와 순정 내비를 핵심에 쓰는 '차에서만 되는' 앱 사례. 고령 고객이 오래, 스스로 판단하며 운전하도록 돕는 브랜드 경험. 데이터를 팔지 않는 신뢰 설계. |
| 사회 | '나이' 대신 '평소의 나'로 고령 운전을 이야기하는 방식. 가족 대화와 공공 상담 창구(치매안심센터)로 자연스럽게 이어지는 길. |

### 6-4. Retention Rate

| 지표 **(가정)** | 차량 앱 — 마음 운전 | 차량 앱 — 운전 컨디션 | 가족 앱 |
|---|---|---|---|
| 1개월 | 95% | 85% | 80% |
| 3개월 | 90% | 70% | 65% |
| 6개월 | 85% | 60% | 55% |
| 12개월 | 80% | 50% | 45% |

- 차량 앱 유지 = 설치한 차 중 그달에도 트립이 모이고, 앱 삭제나 "내 데이터 지우기"를 하지 않은 비율. 가족 앱 유지 = 연결된 가족 중 그달 피드를 연 비율.
- **마음 운전이 높은 이유(가정의 근거)**: ① 시동만 걸면 모여 운전자가 할 일이 없습니다. ② 가치가 몇 달에 걸쳐 쌓이는 구조(기준선 → 월 평가)라 지울 이유가 시간이 갈수록 줄어듭니다. ③ 매달 단계·편지·운전 패턴이 가족에게 돌아가 가족이 운전자에게 다시 말을 거는 고리가 생깁니다.
- **운전 컨디션이 낮은 이유**: 피로·장거리처럼 필요한 날이 띄엄띄엄이라 관심이 덜 이어집니다. 쉬어 가기와 주간 막대그래프로 보완합니다.
- **초기 이탈 대책**: 기준선이 쌓이기 전 몇 달이 가장 약한 구간이라, 지난 기록 가져오기(기준선을 앞당김), 주차 뒤 오늘의 한 줄, 쉬어 가기, "N개월 · N트립을 모았어요" 진행 표시로 첫 달부터 쓸 이유를 줍니다.
- **측정 방법(계획)**: 차량 활성은 서버의 월·일 요약 행으로 추가 수집 없이 셀 수 있습니다. 가족 활성은 피드 연 횟수를 사람 단위 집계로만 남기는 기능을 출시 때 더합니다.

### 6-6. 사업성 정리

- **타깃**: 빠르게 늘어나는 60세 이상 운전자와 그 가족, 그리고 같은 차량 플랫폼의 20~50대.
- **사용자 확보**: 첫 실행에서 태어난 해로 모드가 정해지고, 운전자 한 명이 가족 여러 명을 초대해 사용자가 함께 늘어납니다. Pleos Connect 탑재 차량이 늘수록 대상이 커집니다.
- **지속 이용**: 자동 수집 + 월 단위 가치 축적 + 매달 가족에게 돌아가는 요약·편지·푸시.
- **확대**: 실주행 검증으로 지표 신뢰를 높이고, 제휴(블루링크, 공공 상담 창구)와 해외 시장으로 넓힙니다.
