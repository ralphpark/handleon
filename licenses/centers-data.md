# 치매안심센터 목록 출처

`car/app/src/main/assets/centers.csv` 는 공공데이터포털의 **전국치매센터표준데이터**에서 만들었습니다.

- 출처: https://www.data.go.kr/data/15021138/standard.do (지방자치단체 표준데이터, 갱신 주기 연간)
- 받은 날: 2026-10-23 (포털 수정일 2026-06-19)
- 데이터기준일: 제공 기관마다 다르며 2020-12-14 ~ 2026-09-15
- 남긴 열: 치매센터명 → `name`, 소재지도로명주소(없으면 지번주소) → `address`, 운영기관전화번호 → `phone`, 위도 → `lat`, 경도 → `lon`
- 정리: 339행 중 같은 센터를 도와 시군이 따로 올린 줄(전화가 같고 1km 안)은 기준일이 최신인 것만 남겨 306곳

다시 만들기:

```
python3 -I tools/centers_csv.py car/app/src/main/assets/centers.csv
```

가까운 곳 계산은 차 안에서만 하며, 위치는 밖으로 보내지 않습니다.
